# 瞳学星球 · 眼球大冒险 adventure.html 整体重构（星空幻想电影绘本 + 科普冒险游戏）

## 问题 / 用户 / 目标

**问题**：当前 `adventure.html` 反复出现「巨大圆形浅绿色背景 + 被放大裁切的小光仔头部」视觉，导致整个首屏无法阅读；且页面层级（Hero / 探索地图 / 三栏 / 小游戏）混乱，不符合用户给的「星空幻想电影绘本 + 游戏化科普」信息架构。

**用户**：6-15 岁学生 + 家长。

**目标**：按用户给出的 13 条规范与视觉层级，完整重构 adventure.html 的信息架构与视觉组件，确保：无巨圆人物、卡片玻璃质感、色彩（深空蓝/绿/星光金）一致、导航高亮、Hero 小光仔为独立透明角色且位于右上装饰层、三栏内容（任务卡 250px / 眼球结构 flex:1 / 奖励 280px）完整、底部 4 小游戏卡片可用、响应式在 1920/1440/1366/1280 无横向滚动和裁切。

**非目标**：

- 不修改其他 HTML 页面（index / qa / hero / vision-exploration / decoder / selftest / eye-test / eyeball-adventure）

- 不删除或重生成任何图片素材

- 不修改 `js/main.js` 现有页面跳转与 DOM 钩子

- 不实现新的玩法交互（仅把卡片入口、5 个探索节点、奖励按钮、弹窗基础连接保留，不重写游戏）

## 功能需求

1. **顶部导航**

   - 横向布局：左 Logo「护眼小卫士」；中菜单（首页 / 眼球大冒险 / 视界探索站 / 天书解码器 / 护眼小英雄 / 护眼问答机）；右：语音朗读按钮 + 用户头像

   - 当前页「眼球大冒险」高亮：绿色胶囊或绿色文字+下划线

   - 高度约 80px；半透明深蓝玻璃背景；`border-bottom: 1px solid rgba(255,255,255,.12)`
2. **Hero 冒险主视觉**

   - 高度 420\~480px；左 45% 放标题和 5 节点、右上放完整小光仔+飞船装饰

   - 左上小标签「🎯 第一模块 · 冒险篇」；大标题「眼球」浅蓝白渐变 + 「大冒险」金黄渐变；副标题「跟着小光仔进入眼睛王国，探索眼睛的秘密！」

   - 标题下方横向 5 节点圆形玻璃按钮：01 认识眼睛 / 02 为什么近视 / 03 晶状体 / 04 光线旅行 / 05 终极挑战；节点用连线串起

   - Hero 底部分别显示「⭐ 1280 积分」与「🧑‍🚀 眼球探索家 LV.2」
3. **小光仔（Hero 右上角色）**

   - 独立透明 `<img>` 元素；`position: absolute; right: 4~8%; top: 50% translateY(-50%)`

   - 桌面宽度 280\~420px 之间；但不能超过 Hero 高度的 70%；使用 `object-fit: contain`

   - 禁止：圆形头像容器 / object-fit:cover / background-image / 大面积浅绿色底出现
4. **Hero 右侧氛围层（视觉中心：小光仔 + 飞船 + 眼球星球）**

   - 用 `assets/images/vision/island-eye-full.png` + `spaceship.png` + `star-big/small.png` 组合

   - 可加柔和蓝色光晕、虚线轨道、漂浮星点、小星球；但不能形成巨大人物背景
5. **探索主区三栏**

   - 左 250px「小光仔任务卡」：深蓝玻璃 24px 圆角；顶小光仔头像、正文「嗨！我是小光仔\~」+ 任务说明；黄色可用于重点词

   - 中 flex:1「眼球结构探索区」：白色/奶油浅玻璃卡；眼球剖面示意图；5 个探索点（角膜/瞳孔/晶状体/视网膜/视神经）按路径排列；每点编号+星星+名字+知识，点击可高亮放大

   - 右 280px「章节奖励/进度卡」：标题「→ 完成本章可获得 ←」+ 三项奖励 + 探索进度 2/5 + 进度条 + 绿色渐变按钮「去挑战本章 →」
6. **底部趣味小游戏**

   - 四个横向深蓝玻璃卡片，编号 + 图标 + 标题 + 一句简介 + 绿色「开始游戏」按钮

   - 四款命名严格按：光线迷宫 / 找近视怪兽 / 拼拼眼球 / 眼球旅行
7. **背景**

   - 继续使用现有星空素材 `planet-scene.png` 作为背景层；`cover + center top`；允许叠加极轻微 CSS 星点闪烁 / 星云 / 光晕，但不能让素材的绿色山丘圆盘再次占据画面

## 非功能需求

1. **无巨圆人物**：任何状态下不能出现小光仔作为大圆盘或被 object-fit:cover 裁切。
2. **独立命名空间**：页面新增的样式统一挂在 `body.page-adventure .adv2-*` / `.adventure-page *` 层级下；禁止覆盖通用 `body / img / button / .card`。
3. **兼容桌面主流分辨率**：1920×1080 / 1440×900 / 1366×768 / 1280×720 均无横向滚动条、无裁切、无卡片重叠。
4. **保留功能**：不删除 `#advStepper` / `#advPartModal` / `#advPartNextBtn` / 页脚 footer / `main.js` 引入。
5. **卡片 UI**：`border-radius 20~28px；backdrop-filter blur(10~18)；rgba 背景；1px 白蓝玻璃边；0 10~35px 阴影`。
6. **颜色**：`#06183D / #08295B / #0B3670 / #FFFFFF / #DDF3FF / #78C943 / #A5E85A / #FFD45A / #FFB72E / #65C8FF`。

## 约束 / 依赖 / 假设

- **素材不变**：仅能使用 `assets/images/`（尤其是 `xiaoguangzi-new.png`、`planet-scene.png`、`vision/*.png`）。

- **图片尺寸确认**：`xiaoguangzi-new.png` 1024×1536 原始尺寸，若未给透明背景则通过「严格 contain + 绝对定位 Hero 右上、不要超过 hero 70% 高度」的方式避免出现巨大浅绿圆盘；若浏览器仍在原图四角透出浅绿色背景，则允许加 `mix-blend-multiply` 或 1px 透明 padding 作轻微处理，但**绝对禁止 border-radius + 放大**。

- `main.js` 可能监听导航 `.nav-link[data-page]`、`#advStepper .adv-step`、`data-close-modal`、弹窗开闭；新结构保留所有旧 id/class 并在需要时并行添加 `adv2-*` 视觉类，避免逻辑失活。

## 验收标准 Acceptance Criteria

### Rule（可观测真假值）

- AC01：首屏不再出现 width>800px 的小光仔容器，且不存在任何将小光仔设为 background-image / border-radius 50% / object-fit cover 的 CSS。

- AC02：`body.page-adventure` 页面背景层（例如 `.ad-bg-layer` 或等价背景容器）仅使用 `planet-scene.png` + 轻微 CSS 星层，使用 `background-size:cover / center top`。

- AC03：顶部导航栏高度 70–88px；半透明深蓝玻璃；存在「眼球大冒险」当前页高亮样式；未改动菜单顺序与跳转链接。

- AC04：Hero 总高度（不含 margin/padding 外扩）在 420px 到 540px 之间。

- AC05：Hero 左侧信息宽度约占 Hero 宽 42\~48%；包含章节标签 + 两行式大标题 + 副标题 + 横向 5 节点圆形按钮 + 积分与等级。

- AC06：Hero 右上小光仔为独立 `<img>`，CSS 宽 ≤420px 且 ≤Hero 高 70%，`object-fit:contain`，`z-index` 高于背景低于卡片前景。

- AC07：探索主区为三栏布局 `250px | 1fr | 280px`，左为任务卡、中为眼球结构探索卡、右为奖励进度卡（奖励卡 sticky top:88\~96px）。

- AC08：眼球结构探索卡中，5 个站点（角膜/瞳孔/晶状体/视网膜/视神经）都有可点击节点且保持与下方 #advStepper 不冲突。

- AC09：底部 4 个小游戏卡片（光线迷宫 / 找近视怪兽 / 拼拼眼球 / 眼球旅行）全部显示，每卡有编号+图标+标题+简介+绿色按钮。

- AC10：1920/1440/1366/1280 四种宽度下页面宽度不溢出视口（`document.body.scrollWidth <= window.innerWidth`）。

- AC11：所有保留 id（`advStepper / advPartModal / advPartNextBtn / advPartTitle / advPartIcon / advPartDesc / advPartTipText / footer` 等）仍出现在 DOM 中，未被移除。

- AC12：未改动 `main.js` 与其它 HTML 文件；控制台未新增 404 图片。

### Rubric（0-2 质量维度，≥2 通过阈值？改为 0-2：阈值≥1 即基础可用，2 为高质量。本项目整体质量阈值≥1.6/2）

- R1：**绘本氛围 / 星空层级**（2=多层但克制，星云/星点/星球不抢内容；1=存在但平庸；0=大片纯色或幼稚）。≥1.6

- R2：**小光仔视觉正确度**（2=角色完整，全身，右上装饰，不出现任何绿色底；1=完整但略偏；0=仍有大圆/头占满/裁切）。≥1.8

- R3：**卡片一致性**（2=圆角/玻璃边/发光/阴影完全统一；1=基本一致但 1-2 处偏差；0=卡片风格混乱）。≥1.6

- R4：**信息层级**（2=标题→节点→三栏→小游戏 层级清晰、留白合理、紧凑但不拥挤；1=可读但间距略失衡；0=堆叠混乱）。≥1.6

- R5：**响应式鲁棒性**（2=4 档分辨率全显示完整；1=1 档小问题但可用；0=≥1 档裁切/溢出）。≥1.6
