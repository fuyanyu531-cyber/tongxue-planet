# 从这里开始

双击“打开首页.html”。首页有三个真实链接：眼球大冒险、视界探索站、天书解码器。

01-首页：参考提供的首页界面图制作，网页覆盖文字纠正“世界探索站”为“视界探索站”。原始 JPG 未修改。
02-眼球大冒险：眼球冒险主流程、章节视频和小游戏中心。
03-视界探索站：近视、镜片和配镜学习，含配镜动画。
04-天书解码器：验光单学习和解读。
05-拓展功能：原有打卡、问答和视力工具，保留供学习页内部链接使用。
公共资源：多个模块共用的样式、交互和图片。

每个主要模块均含“代码、配图、视频”。没有独占视频的模块，视频目录为空。修改页面结构看 HTML；修改外观看“样式.css”；修改行为看“交互.js”。带数字后缀的交互文件是保留原顺序拆出的脚本，不能随意交换。

共用图片存放在公共资源，模块独占图片存放在模块配图中。共享的探索图标统一归档在03模块的“探索素材”，其他模块可以引用，无需重复复制。

“迁移清单.json”记录每个旧路径与新路径，供维护时查找。内页保留原功能，本轮主要整理结构和接通新首页，并未重做所有内页。

项目根目录中的“旧版备份/整理前完整项目”保留迁移前文件。“工具”不属于运行代码；“项目资料”存需求和原始设计图。

视频推荐通过本地服务预览：在项目根目录运行 python -m http.server 8000，然后打开 http://localhost:8000/ 。浏览器可能需要先点击才允许有声播放。
