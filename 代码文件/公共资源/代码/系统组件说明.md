# 公共系统组件

四个主页面在各自样式之后加载 `系统外观.css`，并通过 defer 加载 `系统导航.js`。

- 角落入口：首页左侧Logo、右侧“登录 / 我的”；子页面只显示返回首页。无横条导航或当前栏目目录。
- 我的：本机昵称弹窗，存储键 `tongxue.profile.v1`。这不是账号认证；没有密码、注册、远程登录或跨设备同步。浏览器禁止存储时展示提示，游客仍可浏览。
- 外观：首页与眼球地图等比适配一屏。探索站和解码器在内部阅读区滚动以保持长内容可访问。四页隐藏旧页脚。
- 小光仔：`小光仔与记录.js` 提供吉祥物悬停放大、对话弹窗、本地操作问答和模块跳转。当前无联网AI调用，不能回答任意问题；以后可在回答层对接后端，不在前端放服务密钥。
- 验光记录：显式点击保存后，将六项双眼数值与时间保存在 `tongxue.decoder.records.v1`，最多50条；支持载入及逐条删除。不保存上传照片，不上传服务器，不与昵称绑定。所有使用同一浏览器的人共享这份本机记录。
- 前端身份最小信息：仅昵称；未来账号认证方式待后端确定，目前不采集密码、手机号、真实姓名、生日等信息。
- 第一部分的视频路径统一维护在 `02-眼球大冒险/代码/视频配置.js`，01与开始探索共用入口，播放器保留返回地图与返回首页。
- 第二部分播放器保留返回任务地图与静音，并提供暂停/继续、播放失败重试、切换到后台暂停。

后续真正接入账号服务时，应替换本机昵称模块并明确接口、身份认证、隐私与部署要求；不要将此体验功能当成已登录账号。
