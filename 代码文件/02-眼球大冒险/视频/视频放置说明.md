# 怎么放视频

1. 把视频放到本文件夹。推荐命名：01-角膜基地.mp4、02-瞳孔黑洞.mp4、03-晶状体水晶宫.mp4、04-视网膜星云.mp4、05-视神经传输站.mp4。
2. 打开旁边“代码”文件夹里的“视频配置.js”。找到对应的 id，例如 '01'。
3. 把该行的 src: '' 改为 src: '../视频/01-角膜基地.mp4'。保留英文引号和逗号。
4. 保存后刷新眼球大冒险页面，点击第一站即可播放。仅复制文件不会自动接入，必须配置 src。

第二站已临时接入“瞳孔科普.mp4”，第三站接入“进入晶状体水晶宫.mp4”，替换时修改对应 src 即可。第一、四、五站尚未提供对应视频，显示“准备中”，不会错误播放其他章节或进入游戏。

推荐 MP4 容器、H.264 视频编码、AAC 音频。视频应带音轨；仅改扩展名不能转换格式。不用接口服务、不用上传网站，即可在本地查看。

可选封面：把图片放在“配图”目录，将 poster 改为 '../配图/01-角膜封面.jpg'。
可选字幕：把 WebVTT 字幕放在本目录，将 captions 改为 '../视频/01-角膜字幕.vtt'。字幕建议通过本地HTTP服务查看。

播放器默认有声。若浏览器阻止有声播放，会显示“播放视频”按钮，点击即可，不会自动退回静音。顶部可返回地图或首页，底部可暂停、静音；结束后由孩子选择下一站，未播放完也可以离开。

新地图图稿：聊天里提供的五站地图尚未保存为本地文件。可将它命名“​​五站探索地图.jpg”放入配图目录，在视频配置.js 中填写 mapImage: '../配图/五站探索地图.jpg'。目前页面按五站布局用现有素材搭建；不同画幅的图稿需要再调整站点位置。

旧游戏没有删除，在“小游戏中心.html”中保留。旧的自动游戏流程备份在项目根目录“旧版备份/眼球游戏流程-改视频前”。当前主入口只进入视频地图。
